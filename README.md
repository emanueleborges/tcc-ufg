# tcc-ufg

Projeto de TCC da Universidade Federal de Goiás (UFG): chatbot com LLM

## Descrição

Este repositório contém o projeto de TCC da UFG para desenvolvimento de um chatbot baseado em modelo de linguagem grande (LLM). O objetivo é criar uma interface capaz de entender perguntas em linguagem natural e fornecer respostas relevantes.

## Funcionalidades

- Integração com modelo de linguagem (LLM)
- Conversa em linguagem natural
- Base para personalização de domínio

## Tecnologias

- HTML/CSS/JavaScript (front-end)
- Node.js / Python / outro back-end (especificar conforme implementação)
- API de modelo de linguagem (ex. OpenAI, Hugging Face, etc.)

## Como usar

1. Clone este repositório:
   ```bash
   git clone https://github.com/<seu-usuario>/tcc-ufg.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd tcc-ufg
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
   ou
   ```bash
   pip install -r requirements.txt
   ```
4. Configure as credenciais da API de LLM em variáveis de ambiente ou arquivo de configuração.
5. Execute o projeto:
   ```bash
   npm start
   ```
   ou
   ```bash
   python app.py
   ```
